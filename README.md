### 🃏 GitHub DevCard — Next.js · TypeScript · Tailwind · shadcn/ui

Search any GitHub username to view live stats, compare two profiles head-to-head, browse trending repos by language, and export a shareable profile card as a PNG. Built on the App Router with a dedicated API layer for GitHub rate-limit handling, fetch-based ISR caching, and per-page dynamic SEO — `generateMetadata` and personalized `next/og` social preview images on every dynamic route.
