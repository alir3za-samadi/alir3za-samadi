## 🚀 Features

- 🔍 **GitHub Profile Search:** Instantly fetch and display detailed user metrics, repositories, and activity.
- ⚔️ **Developer Comparison:** Compare two GitHub profiles side-by-side with clear visual cards.
- ⚡ **Optimized Data Fetching:** Powered by TanStack Query for smooth caching, state management, and fast transitions.
- 🎨 **Modern UI/UX:** Built with Base UI, Shadcn UI components, Lucide Icons, and custom dark mode styling.
- 📱 **Fully Responsive:** Smooth navigation across all screen sizes with accessible mobile menus.
